# Ewan Moorcroft

I am an MSc Data Science and Artificial Intelligence student at the University of Liverpool,
finishing in September 2026. I completed my BSc in Geography at the University of Liverpool in June 2025.

I work mainly in Python across spatial data, GIS, forecasting, statistical modelling, and machine
learning. My Geography background is useful when working with place, scale, and environmental context,
while my MSc builds on that with data science and AI methods.

All my portfolio code is kept in one repository: [Ewan Moorcroft Portfolio](https://github.com/EwanMoorcroft/Ewan-Moorcroft-Portfolio).

## Selected projects

- [Liverpool urban accessibility](https://github.com/EwanMoorcroft/Ewan-Moorcroft-Portfolio/tree/main/projects/liverpool-urban-accessibility): examines workplace movement across Liverpool using Census data, spatial statistics, Python and R.
- [FPL next-gameweek forecasting](https://github.com/EwanMoorcroft/Ewan-Moorcroft-Portfolio/tree/main/projects/fpl-forecasting): forecasts player points using only information available before the next gameweek, with batch scoring and a small read-only local service.
- [Tree LiDAR benchmark](https://github.com/EwanMoorcroft/Ewan-Moorcroft-Portfolio/tree/main/projects/tree-lidar-benchmark): compares individual-tree segmentation methods under one reproducible evaluation protocol for terrestrial LiDAR data.
- [Chest X-ray classification](https://github.com/EwanMoorcroft/Ewan-Moorcroft-Portfolio/tree/main/projects/chest-xray-classification): classifies public chest X-ray images into three categories while keeping exact image copies in the same data partition.

I also use scikit-learn, PyTorch, pandas, NumPy, SQL, QGIS, R, pytest, and GitHub Actions. The main
portfolio gives the data sources, tests, limitations, and result status for each project.
