# Ewan Moorcroft

MSc Data Science and Artificial Intelligence student at the University of Liverpool, with a BSc
in Geography from the same institution.

I build reproducible machine learning systems, with particular interests in computer vision, 3D
spatial data, forecasting, geospatial analysis, and rigorous model evaluation.

## Selected work

- [Tree LiDAR instance benchmark](https://github.com/EwanMoorcroft/Ewan-Moorcroft-Portfolio/tree/main/projects/tree-lidar-benchmark) — evaluation of six instance-segmentation routes across 49.7 million held-out points.
- [FPL next-gameweek forecasting](https://github.com/EwanMoorcroft/Ewan-Moorcroft-Portfolio/tree/main/projects/fpl-forecasting) — leakage-controlled temporal modelling with expanding-window evaluation and Docker packaging.
- [Chest X-ray classification](https://github.com/EwanMoorcroft/Ewan-Moorcroft-Portfolio/tree/main/projects/chest-xray-classification) — transfer learning with dataset identity, duplicate containment, and calibration-aware evaluation.
